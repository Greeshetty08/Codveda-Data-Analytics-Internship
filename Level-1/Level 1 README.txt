# Iris Dataset - Exploratory Data Analysis (EDA)

## Objective

The objective of this project is to perform Exploratory Data Analysis (EDA) on the Iris dataset to identify patterns, relationships, and statistical properties of the data.

## Tools Used

* Python
* Pandas
* Matplotlib
* Seaborn

## Dataset Features

* Sepal Length
* Sepal Width
* Petal Length
* Petal Width
* Species

## Analysis Performed

### Data Inspection

* Checked dataset structure
* Verified data types
* Checked for missing values

### Summary Statistics

Calculated:

* Mean
* Median
* Mode
* Standard Deviation

### Visualizations

* Histograms
* Boxplots
* Scatter Plots
* Correlation Heatmap
* Pairplot

## Key Findings

* Petal Length and Petal Width show strong positive correlation.
* Setosa species is clearly separable from the other species.
* No significant missing values were found.
* Feature distributions are generally well balanced.

## Conclusion

The EDA process provided insights into feature relationships and species separation. The dataset is clean and suitable for machine learning tasks such as classification.
