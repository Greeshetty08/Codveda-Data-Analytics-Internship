# Iris Dataset - Exploratory Data Analysis (EDA)

## Objective

The objective of this project is to perform Exploratory Data Analysis (EDA) on the Iris dataset to understand the distribution of features, identify relationships between variables, and derive meaningful insights.

## Tools Used

* Python
* Pandas
* Matplotlib
* Seaborn

## Dataset

The Iris dataset contains measurements of iris flowers from three different species:

* Setosa
* Versicolor
* Virginica

### Features

* Sepal Length
* Sepal Width
* Petal Length
* Petal Width
* Species

## Analysis Performed

### Data Inspection

* Loaded the dataset using Pandas
* Examined dataset structure and data types
* Checked for missing values

### Statistical Analysis

Calculated:

* Mean
* Median
* Mode
* Standard Deviation

### Visualizations

* Histograms
* Boxplots
* Scatter Plot
* Correlation Heatmap
* Pairplot

## Key Findings

* Petal Length and Petal Width have a strong positive correlation.
* Setosa species can be clearly distinguished from the other species.
* The dataset contains no significant missing values.
* Feature distributions are suitable for machine learning applications.

## Conclusion

Exploratory Data Analysis helped in understanding the characteristics of the Iris dataset and identifying relationships between features. The dataset is clean, well-structured, and suitable for classification tasks.
