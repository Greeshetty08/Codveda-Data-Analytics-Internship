# House Price Prediction using Linear Regression

## Objective

The objective of this project is to build a Linear Regression model to predict house prices based on various housing features and evaluate its performance using regression metrics.

## Tools Used

* Python
* Pandas
* Scikit-learn
* Matplotlib

## Dataset

The dataset contains housing-related features such as crime rate, number of rooms, property tax rate, accessibility, and other factors affecting house prices.

## Methodology

### Data Preparation

* Loaded the dataset using Pandas
* Separated features and target variable
* Split the dataset into training and testing sets

### Model Development

* Applied Linear Regression using Scikit-learn
* Trained the model on the training dataset
* Generated predictions on the test dataset

### Evaluation Metrics

* R² Score: 0.6688
* Mean Squared Error (MSE): 24.2911

### Visualization

* Actual vs Predicted House Prices Scatter Plot

## Results

The model achieved an R² Score of approximately 0.67, indicating that it explains a significant portion of the variance in house prices. The scatter plot shows a positive relationship between actual and predicted values.

## Conclusion

Linear Regression was successfully implemented to predict house prices. The model demonstrates a reasonable predictive capability and provides a foundation for more advanced regression techniques.
